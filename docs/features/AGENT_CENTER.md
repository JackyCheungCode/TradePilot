# TradePilot Agent Center

The first-level navigation entry **TradePilot Agent 智能体** is placed before 潜客发现. It uses a dedicated animated AI orb mark (rotating gradient ring, luminous core and pulse).

Navigation: Agent 工作台、Agent 市场、Agent 编排、外部 Agent 接入、执行记录、审批中心、Agent 设置.

Open ecosystem: REST API, MCP and Webhook integrations are supported as target protocols. Integrations must pass capability discovery, connection tests, permission review and server-side credential encryption before activation.

Execution policy: search, discovery, enrichment, company research, scoring and analysis may run automatically within budgets. Sending email/messages, bulk CRM imports, bulk customer changes, deletion and merges require explicit human approval. Approval must bind to an immutable operation snapshot and be invalidated by material parameter changes.

The initial commit establishes navigation, animated identity and the seven UI areas. It does not yet claim a live Agent execution engine or external connector: execution, encrypted credential vault, protocol adapters and approval executor remain backend milestones.
